# Калькулятор траектории снаряда

Учебный проект на языке C, который рассчитывает траекторию движения снаряда по начальной скорости и углу броска.

## Возможности

Программа рассчитывает:

- время полёта;
- дальность полёта;
- координату X;
- координату Y.

## Используемые формулы

Горизонтальная составляющая скорости:

`vx = v0 * cos(angle)`

Вертикальная составляющая скорости:

`vy = v0 * sin(angle)`

Координата X:

`x(t) = v0 * cos(angle) * t`

Координата Y:

`y(t) = v0 * sin(angle) * t - g * t² / 2`

Время полёта:

`T = 2 * v0 * sin(angle) / g`

Дальность:

`L = v0² * sin(2 * angle) / g`

## Входные данные

Пользователь вводит:

- начальную скорость в м/с;
- угол броска в градусах.

## Пример работы

Ввод:

```text
Начальная скорость в м/с: 20
Угол броска: 45
```

Результат:

```text
Время полёта: 2.88
Дальность: 40.77
Координата X: 40.77
Координата Y: 0.00
```

## Ограничения модели

В расчётах используется идеализированная модель движения:

- сопротивление воздуха не учитывается;
- ускорение свободного падения `g = 9.81 м/с²`;
- начальная и конечная высоты одинаковые.
